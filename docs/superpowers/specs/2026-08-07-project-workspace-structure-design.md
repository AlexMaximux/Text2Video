# Project Workspace Structure Design Document

**Date:** 2026-08-07  
**Status:** Approved by User  
**Goal:** Organize all video assets into dedicated project subdirectories under `projects/` (e.g., `projects/Video_YYYYMMDD_HHMMSS_Title/`) to eliminate root folder clutter and prevent accidental file overwrites.

---

## 1. Directory Architecture

```
Text2Video/
├── claude_prompt.py
├── elevenlabs_prompt.py
├── transcribe_audio.py
├── batch_generate_millo.py
├── make_final_video.py
├── pipeline.py
├── history_topics.txt
├── modules/
│   ├── project_manager.py     # Central project workspace manager
│   ├── ...
│
└── projects/                                   # Dedicated project output workspace
    └── Video_20260807_1937_WiredToBelong/        # Self-contained project directory
        ├── senario.txt                         # 1. Script generated by Claude
        ├── voice.mp3                           # 2. Voice audio generated by ElevenLabs
        ├── transcript.txt                      # 3. Whisper timed transcript
        ├── words.json                          # 4. Whisper word-level timestamps
        ├── images/                             # 5. Generated slide images
        └── final_video.mp4                     # 6. Rendered MP4 video with captions
```

## 2. Project Manager Module (`modules/project_manager.py`)

A centralized helper module responsible for locating, creating, and resolving active project directories.

### Functions:
1. `get_projects_dir() -> Path`: Returns `Path("projects")` and ensures it exists.
2. `create_new_project_dir(title_hint: str = None, project_name: str = None) -> Path`:
   - If `project_name` is explicitly passed (e.g. `Video_01`), creates `projects/Video_01`.
   - If `project_name` is omitted, generates folder name based on current timestamp and title slug, e.g. `projects/Video_20260807_1937_WiredToBelong`.
3. `get_latest_project_dir() -> Path`: Finds the most recently modified directory inside `projects/`. Fallbacks to creating a default project directory if none exists.
4. `resolve_project_dir(project_arg: str = None, auto_create_if_none: bool = False, title_hint: str = None) -> Path`:
   - If `project_arg` provided: resolves `projects/<project_arg>`.
   - If `project_arg` omitted and `auto_create_if_none` is True (for step 1 `claude_prompt.py`): creates a new project directory.
   - If `project_arg` omitted and `auto_create_if_none` is False (for downstream steps): returns latest active project directory from `get_latest_project_dir()`.

## 3. Script CLI & Path Integration

- **`claude_prompt.py`**:
  - Accepts optional `--project` (str).
  - Resolves target project directory via `resolve_project_dir(args.project, auto_create_if_none=True, title_hint=script_title)`.
  - Saves script to `projects/<ProjectDir>/senario.txt`.
- **`elevenlabs_prompt.py`**:
  - Accepts optional `--project` (str).
  - Resolves active project directory.
  - Default input: `projects/<ProjectDir>/senario.txt` -> Default output: `projects/<ProjectDir>/voice.mp3`.
- **`transcribe_audio.py`**:
  - Accepts optional `--project` (str).
  - Default input: `projects/<ProjectDir>/voice.mp3` -> Default outputs: `projects/<ProjectDir>/transcript.txt` and `projects/<ProjectDir>/words.json`.
- **`make_final_video.py`**:
  - Accepts optional `--project` (str).
  - Default inputs: `projects/<ProjectDir>/images`, `projects/<ProjectDir>/voice.mp3`, `projects/<ProjectDir>/transcript.txt`, `projects/<ProjectDir>/words.json` -> Default output: `projects/<ProjectDir>/final_video.mp4`.
- **`pipeline.py`**:
  - Accepts optional `--project` (str).
  - Runs full end-to-end flow inside the resolved project directory.
