--------------------------------------------------------------------------------
The user requested a Python automation script based on the Browser2API framework
that opens Chrome, navigates to ElevenLabs Text-to-Speech synthesis page, selects 
the voice ID '2styzLg7OSeuhPP6uQ26', inputs text from 'senario.txt', clicks 
'Generate speech', automatically downloads the generated audio as 'Senario.mp3', 
and closes the browser automatically upon completion.
